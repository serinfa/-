# 내 손글씨 폰트 (Handwriting → Font)

평소 쓰는 짧은 문장을 손글씨로 따라 쓰기만 하면, 그 글씨체로 된 폰트(.ttf)를 만들어 주는 앱입니다.
한글은 완성형 글자를 전부 쓰지 않아도, 초성/중성/종성 자모만 몇 개 쓰면 조합해서 안 써본 글자도 자동으로 만들어 줍니다.

## 구조

```
handwriting-font-app/
  mobile/   # Expo(React Native) 앱 — 손글씨 캡처, 로컬 저장, 진행 상황, 폰트 내보내기
  server/   # Node/Express 서버 — 획(stroke) 데이터를 폰트 파일(.ttf)로 변환
```

### 왜 앱 + 서버로 나눴나요?

- **캡처는 온디바이스**: 손가락으로 그린 궤적(획)을 좌표 그대로 저장하기 때문에, 사진을 스캔해서
  트레이싱하는 방식보다 훨씬 정확하고 빠릅니다. 인터넷 연결 없이도 계속 쓸 수 있어요 (로컬 저장 우선).
- **폰트 생성은 서버**: 실제 `.ttf` 폰트 파일을 만드는 작업(윤곽선 계산, 자모 조합, OpenType 어셈블리)은
  React Native 런타임보다 Node.js에서 훨씬 안정적으로 처리할 수 있어서 분리했습니다. "폰트 만들기"를
  누를 때만 지금까지 모은 손글씨 데이터를 서버로 보내고, 완성된 폰트 파일을 받아옵니다.

## 동작 원리

1. **쓰기**: 앱이 매일 짧고 자연스러운 문장(또는 직접 입력한 문장)을 보여주고, 사용자가 글자 하나하나를
   자기 칸에 손으로 씁니다. 어떤 글자를 쓰고 있는지 이미 알고 있기 때문에(문자 인식 불필요), 획 데이터를
   해당 유니코드 문자에 바로 매핑합니다.
2. **저장**: 획 좌표(스트로크)를 기기에 로컬로 저장합니다(AsyncStorage). 같은 글자를 다시 쓰면 최신
   버전으로 덮어써서 계속 "학습"(사실은 갱신)됩니다.
3. **폰트 만들기**: "동기화하고 폰트 만들기"를 누르면 —
   - 모든 획 데이터를 서버로 보내고,
   - 서버는 각 획을 펜으로 그은 것처럼 두께가 있는 윤곽선(polygon)으로 변환하고 (`server/src/strokeOutline.js`),
   - 직접 쓴 한글 자모들을 조합해서 아직 안 써본 완성 글자를 합성하고 (`server/src/fontFromStore.js`, `hangul.js`),
   - 이 모든 윤곽선을 `opentype.js`로 조립해 실제 `.ttf` 파일을 만들어 (`server/src/fontBuilder.js`)
   - 앱이 파일을 받아 기기에 저장하고 공유 시트로 내보냅니다.

## 실행 방법

### 서버

```bash
cd handwriting-font-app/server
npm install
npm start        # http://localhost:4000
npm test         # 핵심 로직(획→윤곽선→자모 조합→폰트) 검증 스크립트
```

### 앱

```bash
cd handwriting-font-app/mobile
npm install
npx expo start
```

- 실기기(Expo Go)나 시뮬레이터에서 실행하세요.
- "폰트 만들기" 화면에서, 서버를 실행 중인 컴퓨터와 **같은 Wi-Fi**에 연결한 뒤 그 컴퓨터의 IP 주소를
  입력해야 합니다 (예: `http://192.168.0.10:4000`). 컴퓨터의 로컬 IP는 `ifconfig`/`ipconfig`로 확인할 수 있어요.

## 알려진 한계 (다음에 개선할 부분)

- **자모 조합은 근사치입니다.** 초성/중성/종성을 정해진 4~6개 레이아웃 박스에 크기 조절해서 배치하는
  단순한 규칙이라, 실제 전문 폰트만큼 자연스럽지는 않습니다. 특히 겹받침(예: ㄳ, ㄶ)은 두 자음을 나란히
  붙이는 방식으로 근사합니다.
- **동그란 폐곡선 획(예: ㅇ, 알파벳 o)**은 두께가 매우 두꺼우면 안쪽 구멍이 뭉개져 보일 수 있습니다
  (완전한 폴리곤 불리언 연산 대신 안/바깥 윤곽선을 분리하는 단순한 방식 사용).
- **모든 글자가 같은 폭(advance width)**으로 나옵니다. 손글씨 특성상 다양한 폭을 자동 추정하는 기능은
  아직 없어서, 지금은 모노스페이스에 가깝게 보일 수 있습니다.
- **서버가 항상 켜져 있어야** 폰트를 만들 수 있습니다(캡처 자체는 오프라인 가능). 실제 배포판이라면
  이 서버를 클라우드에 올리거나, 폰트 조립 로직을 기기 내에서 직접 돌리는 방식으로 바꿀 수 있습니다.
- **완성된 .ttf를 iOS/Android 시스템 폰트로 등록하는 절차**는 OS마다 다르고 별도 설정이 필요합니다
  (안드로이드는 커스텀 폰트 지원 키보드/런처 필요, iOS는 프로파일 설치 또는 서드파티 폰트 앱 필요). 이 앱은
  `.ttf` 파일을 만들어 공유하는 데까지만 담당합니다.
